# Pokemon React

A web app to browse Pokemon, search by name, and view details like moves, abilities, height and weight. Data comes from [PokeAPI](https://pokeapi.co/). The app can be installed to your home screen as a Progressive Web App (PWA).

## Features

- Pokemon cards with sprite, name, types and base stats
- "Load more" pagination
- Search by exact name
- Detail view with moves, abilities, height and weight
- Installable as a PWA

## Setup

Requires Node.js 18 or newer.

```bash
# Clone the repo
git clone https://github.com/<your-username>/pokemon-react.git
cd pokemon-react

# Install dependencies
npm install

# Start the dev server
npm run dev

# Build for production
npm run build

# Preview the production build
npm run preview
```
